# Portfolio images

Files in this folder are served at `/manus-storage/<name>`. The folder name is
kept for historical URL compatibility (content and OG tags reference these
paths verbatim) — it is plain static hosting, nothing Manus-specific remains.

Note: the five original files carry a `.png` extension but are actually WebP —
browsers render them fine either way. Keep existing filenames unchanged; new
images for `projects.ts` entries can simply be added here and referenced as
`/manus-storage/<filename>`.
