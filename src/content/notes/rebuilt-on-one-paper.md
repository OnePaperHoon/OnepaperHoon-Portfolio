이전 사이트는 자동 생성 도구로 만든 React SPA였다. 돌아가긴 했지만 마음에 들지 않는 점이 분명했다.

- 554줄짜리 페이지 컴포넌트 하나에 모든 게 들어 있었다.
- 쓰지도 않는 UI 컴포넌트가 50개쯤 깔려 있었다.
- 프로젝트 하나를 추가하려면 TypeScript 객체에 필드 20개를 직접 써야 했다.
- 글을 쓸 곳이 없었다. Notes 섹션은 제목만 있는 장식이었다.
- 무엇보다, 어디서 본 것 같은 사이트였다.

## 새로 지은 것

**콘텐츠는 마크다운 파일 하나.** `src/content/work/`에 파일을 하나 추가하면 홈 카드, 상세 페이지, 숫자, 사이트맵에 전부 반영된다. 이 글도 `src/content/notes/`에 있는 마크다운 파일이다.

**정적 사이트.** Astro로 빌드한 HTML을 Cloudflare Workers 정적 자산으로 올린다. 서버도 DB도 없다.

**종이 한 장.** 내 이름 '한장훈'에서 '한 장'을 가져왔다. three.js로 만든 종이 한 장이 스크롤을 따라다니며 각 섹션의 핵심 한 줄을 들고 있다. 페이지 끝에서는 종이비행기로 접혀서 날아간다. 접기는 실제 종이접기처럼 접는 선을 기준으로 메시를 나누고 순서대로 회전시켜서 만들었다.

페이지를 넘어가도 종이는 같은 종이다. 링크를 누르면 그 종이가 화면을 덮을 만큼 커져서 다음 페이지가 되고, 다시 작아지며 제자리에 내려앉는다. 펼쳐진 종이는 마우스로 잡아 끌 수 있고, 없는 주소로 가면 구겨진 종이 뭉치가 기다린다. 마지막 장의 비행기는 눌러서 날릴 수 있고, 날아가면 새 종이 한 장이 내려온다.

**스크롤은 하루.** 하늘은 셰이더로 그린다. 첫 화면은 방문한 사람의 지금 시각이고, 스크롤을 내릴수록 다음 시간대로 넘어간다. 아침에 오면 새벽에서 시작해 별이 뜨는 노을로 끝나고, 밤에 오면 달밤에서 시작해 한낮으로 끝난다.

**읽지 말고 만져 보기.** 작업 페이지에는 스크린샷 대신 작은 데모가 있다. 설치 CLI의 질문에 직접 답해 보고, 매분 알림이 쌓이는 채널과 메시지 하나만 고쳐지는 채널을 나란히 지켜본다. '지금 돌아가는 것' 종이에 찍힌 FeedLine의 숫자는 실제 서비스에서 가져온 값이다.

**숨은 것들.** 헤더의 연필을 켜면 종이에 낙서할 수 있고, 맨 아래에서 그대로 접어 날릴 수 있다. `` ` `` 키를 누르면 터미널이 열린다 (`help`부터). 밤하늘의 달은 오늘 실제 달 모양이다.

WebGL이 없거나 '동작 줄이기'를 켠 환경에서는 같은 내용이 그냥 종이 카드와 그라데이션 하늘로 보인다.
